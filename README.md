# Jadual Periodisasi Latihan 400m Berpagar — 24 Minggu

Infografik web yang boleh diedit melalui HTML/CSS/JavaScript dan disimpan dalam GitHub. Reka bentuk diinspirasikan oleh carta periodisasi Sains Sukan STPM: tajuk oren, objektif mengikut komponen, garis masa 24 minggu, blok latihan berwarna, nutrisi/psikologi dan graf isipadu-intensiti-prestasi.

## Fail
- `index.html` — infografik kendiri, responsif dan boleh dicetak.
- `README.md` — penerangan projek.

## Cara melihat
Muat turun atau klon repositori, kemudian buka `index.html` dalam pelayar web. Tiada pemasangan atau pustaka luaran diperlukan.

## Cetakan
Gunakan landskap A3 atau “Save as PDF”. Untuk hasil paling hampir dengan rujukan, pilih skala cetakan yang memuatkan satu halaman landskap.

## Nota latihan
Jadual ini ialah contoh perancangan umum, bukan preskripsi individu. Selaraskan fasa dan minggu kejohanan dengan kalendar sebenar. Julat nutrisi perlu disesuaikan dengan atlet dan nasihat jurulatih/pakar pemakanan sukan. “Transisi” di sini diletakkan pada Minggu 23–24 selepas pertandingan sasaran Minggu 20–21.
